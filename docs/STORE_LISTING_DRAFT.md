# Chrome Web Store listing — draft (review before publication)

**Product:** Dongo Adblocker

**Short description:** Block requests to common ad hosts, with an optional local Gmail screen-privacy mode.

**Long description:** Dongo is a lightweight Chrome extension that uses browser-native rules to block selected advertising requests without routing your browsing traffic through an Abinod server. The popup lets you turn ad blocking on or off. An optional Gmail screen-privacy mode blurs the displayed message body on mail.google.com and can be switched off at any time. It does not encrypt email, secure Gmail accounts or provide comprehensive ad blocking. No extension analytics or telemetry is included in this release.

**Disclaimer:** This is a small starter filter list, not an exhaustive ad blocker. Some ads will still appear and some site functionality can be affected by blocked requests. Gmail visual concealment is experimental and does not prevent account access or exposure via developer tools or other devices.

**Store review risk:** General-purpose ad blocking and Gmail concealment could be judged separate purposes under Chrome Web Store policy. Consider publishing the ad-blocking capability alone and treating Gmail concealment as a separate, Gmail-specific future offering if reviewers object. Test with Chrome Web Store policies before releasing both in a single listing.

**Prepublication screenshots:** popup with ad control active; Gmail privacy mode on and off using a throwaway testing account with fake messages; browser settings view (no sensitive emails).

**Required:** public privacy notice URL, Abinod support contact, high-quality icons and screenshots, Store privacy declarations, permission justifications, real Chrome testing, and Chrome Web Store developer account.
